Features

Backtesting Engine

Event-driven, vectorized, and hybrid modes. Purged CV, walk-forward, Monte Carlo.

Strategy Research

Signal generation, regime detection, factor analysis, alternative data integration.

Portfolio Management

Multi-asset, multi-strategy. Position sizing, risk parity, Kelly criterion.

Risk Controls

Real-time risk limits, drawdown controls, correlation monitoring, stress testing.

Live Execution

Multi-broker (Zerodha Kite, CCXT crypto). Smart order routing, TCA.

Observability

Structured logging, metrics, tracing. PnL attribution, strategy health.

Testing

  • 437 tests collected across backend/tests/
  • Unit tests for each module (engine, risk, portfolio, strategies, etc.)
  • Integration tests for broker adapters
  • Backtest validation tests (purged CV, walk-forward)
  • Slow suite (>280s) — run with pytest -x for fast feedback
